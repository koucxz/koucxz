## 个人项目

### [VideoNote](https://github.com/koucxz/video-note)

基于 React 19 和 FastAPI 构建的多模态视频笔记系统，支持异步视频处理、ASR/VLM/LLM 分析、Markdown 笔记版本管理、导出、笔记集合和基于 RAG 的问答。

### [mcp-tools-lint](https://github.com/koucxz/mcp-tools-lint)

面向 MCP Server 的工具质量检查 CLI，支持 stdio、Streamable HTTP 通信方式，以及 JSON Schema 工具契约校验。

### [GenCode](https://github.com/koucxz/gencode-vscode)

基于 Python、LangChain 和 OpenAI API 构建的 VS Code 代码生成插件。在 HTML、WXML、JavaScript 和 TypeScript 文件中使用 `genCode("...")`，读取当前文件及关联文件并生成可插入代码。
